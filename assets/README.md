# assets

## logo.png

Immensus Post logotipi shu papkaga **`logo.png`** nomi bilan joylandi.

Talablar:
- **PNG**, fon shaffof (transparent) bo'lsa eng yaxshisi
- Kengligi kamida **400px** — kichik fayl rasmda xira chiqadi
- Kvadratga yaqin yoki gorizontal shakl yaxshi ishlaydi

Logo har bir rasmning pastki o'ng burchagiga avtomatik qo'yiladi. Ushbu
loyiha `config.yaml` ichida Immensus Post ranglari va 4:5 formatga sozlangan.
O'lchami, joyi va shaffofligi `config.yaml` dagi `image.logo` bo'limida
sozlanadi.

Fayl bo'lmasa — rasm logosiz chiqaveradi, tizim to'xtamaydi.
